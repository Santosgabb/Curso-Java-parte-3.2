# Curso de Java: Orientação a Objetos - Parte 3.2 ☕

Exercícios práticos introdutórios de Programação Orientada a Objetos (POO) em Java, focados na criação de classes, instanciação de objetos e manipulação de atributos e métodos simples.

---

## 📌 Conteúdos Abordados

* **Definição de Classes e Atributos**: Modelação de entidades do mundo real em estruturas de código Java.
* **Instanciação de Objetos**: Utilização do operador `new` e alocação de memória.
* **Métodos Simples**: Criação e invocação de comportamentos sem parâmetros ou retorno direto.
* **Execução**: Criação de classes principais de teste para validação dos fluxos criados.
